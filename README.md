# 🧵 ورشة أناقة - دليل الاستخدام

موقع متجر + مدونة لورشة خياطة نسائية.

## 📁 هيكل الملفات

```
workshop-store/
├── index.html          ← الصفحة الرئيسية (لا تعدليها)
├── post.html           ← صفحة المقالات (لا تعدليها)
├── data/
│   ├── products.json   ← أضيفي/عدلي المنتجات هنا
│   └── blogs.json      ← أضيفي/عدلي قائمة المقالات هنا
└── posts/
    ├── post1.md        ← المقال الأول
    ├── post2.md        ← المقال الثاني
    └── post3.md        ← المقال الثالث
```

## 🛍️ إضافة منتج جديد

افتحي ملف `data/products.json` وأضيفي كائن جديد:

```json
{
  "id": 7,
  "name": "اسم المنتج",
  "desc": "وصف قصير",
  "price": 200,
  "icon": "👗"
}
```

**ملاحظة**: اجعلي `id` فريداً (لا يتكرر).

## 📝 إضافة مقال جديد

### الخطوة 1: أنشئي ملف Markdown جديد
في مجلد `posts/`، أنشئي ملفاً مثلاً `post4.md`

### الخطوة 2: اكتبي المقال
```markdown
# عنوان المقال

محتوى المقال هنا...

## عنوان فرعي

- نقطة 1
- نقطة 2
```

### الخطوة 3: سجلي المقال في القائمة
افتحي `data/blogs.json` وأضيفي:

```json
{
  "id": 4,
  "title": "عنوان المقال",
  "date": "26 أغسطس 2026",
  "excerpt": "ملخص قصير يظهر في الصفحة الرئيسية...",
  "icon": "📝",
  "file": "post4.md"
}
```

## 🎨 تخصيص الألوان

في `index.html` ابحثي عن `:root` وغيّري الألوان:
- `--primary`: اللون الذهبي الرئيسي
- `--dark`: اللون البني الداكن
- `--accent`: اللون الوردي

## 📞 تغيير رقم الواتساب

في `index.html` ابحثي عن `966500000000` واستبدليها برقمكِ مع كود الدولة.
